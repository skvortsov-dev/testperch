# Privacy

TestPerch is a local Chrome extension. It has no analytics, telemetry, advertising, or developer-operated backend.

On opening TestPerch, it shows the last successful browser-session snapshot immediately, checks open Amplitude tabs for a ready session, and prefers the last connected tab. A lightweight readiness check verifies that a recent snapshot still belongs to the same signed-in account without requesting the catalog again. While waiting for sign-in, readiness checks run every five seconds only while the extension window is visible.

On connection, user actions, automatic refresh while the side panel is visible, and a five-minute background alarm, a script runs in an authorized Amplitude tab and uses that tab's existing session to request account, project, deployment, configuration, variant, and testing-assignment data from Amplitude. Background refresh runs only when automatic connection is enabled, a previous connection exists, and an Amplitude tab reports a ready signed-in session. The tab processes assignment lists, which may include other participants' identifiers, to preserve them during changes. Only the current account, configuration metadata, available variants, and memberships of the explicitly selected IDs are returned to the extension. Custom mode processes the email addresses and user/device IDs you enter, including IDs belonging to other people when your Amplitude account has access. Saves send the selected ID and updated Testing assignments to Amplitude; other participants are preserved.

Cookies, passwords, API keys, and tokens are not extracted or stored by TestPerch. The browser attaches existing session credentials to same-origin requests. The extension does not send data to its developer or other third parties. Requests to Amplitude remain subject to its policies and the customer's agreement.

The theme preference and whether automatic connection is allowed are saved locally. The selected tab ID, project ID, selected testing IDs, signed-in account and organization metadata, and the last filtered catalog returned for those IDs are saved in Chrome session storage. This lets the side panel render immediately and lets the background worker update the same snapshot. Cached catalog entries contain configuration metadata, available variants, and memberships only for the selected IDs; they do not contain the full participant lists processed inside the Amplitude tab. Disconnect clears the connection and snapshot and disables automatic connection until the user explicitly reconnects. Chrome also clears session storage when the browser restarts or the extension is reloaded, updated, or disabled. TestPerch does not store credentials. The storage permission also permits removing legacy API-key settings; the alarms permission schedules background refresh; the sidePanel permission keeps the interface available while you navigate between tabs. Scripting and host permissions are limited to app.amplitude.com and app.eu.amplitude.com.

Demo data is fictional and changes only local in-memory state. Uninstalling the extension does not undo assignments already saved in Amplitude.

TestPerch uses this data only to display and manage the Testing assignments you request. It is not sold, used for advertising, or used for credit or lending decisions. Questions or deletion requests can be raised through [GitHub Issues](https://github.com/skvortsov-dev/testperch/issues); do not include private account data in public issues.
